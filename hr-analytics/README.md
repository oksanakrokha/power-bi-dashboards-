# HR Analytics Dashboard


## 📌 Огляд проєкту
Цей проєкт є комплексним **End-to-End рішенням для HR-аналітики (Workforce, Recruitment & Attrition)**, створеним для симуляції реальних бізнес-процесів управління персоналом у 2026 році. 

Головна особливість проєкту — побудова повного конвеєра даних (Data Pipeline): від генерації синтетичних даних за допомогою Python до розгортання on-premises інфраструктури та хмарної синхронізації в Power BI Service / Microsoft Fabric.

---

## 🛠️ Архітектура та Технологічний стек

Для цього навчального проєкту було свідомо обрано складну enterprise-архітектуру, щоб протестувати взаємодію локальних баз даних із хмарними сервісами Microsoft:

1. **Генерація даних (Python):** Створення реалістичних HR-метричних даних та експорт у CSV.
2. **Зберігання (PostgreSQL):** Локальне сховище даних (On-Premises Database), куди імпортувалися таблиці.
3. **Конвеєр (On-Premises Data Gateway):** Налаштування та конфігурація шлюзу для забезпечення безпечної онлайн-передачі даних із локальної БД до хмари.
4. **Обробка та моделювання (Power BI Service / Fabric Wharehouse):** Отримання даних, створення зв'язків та розгортання єдиної **Семантичної моделі (Semantic Model)**, яка виступає як єдине джерело правди (Single Source of Truth).
5. **Візуалізація (Power BI):** Створення інтерактивного дашборду на основі розгорнутої моделі.

---

## 📈 Структура дашборду (4 сторінки)

Дашборд містить глибоку аналітику та розділений на тематичні блоки:

*   **Workforce Overview:** Загальний огляд штату (445 активних співробітників), аналіз складу (Probation, Active, Terminated), плинність кадрів за департаментами та помісячна динаміка звільнень.
*   **Recruitment & Hiring:** Метрики рекрутингу (кількість вакансій, Closure Rate 50.67%, середній час закриття посади — 88 днів), лійки кандидатів за департаментами та моніторинг звільнень новачків у перші 90 днів.
*   **Attrition & Turnover:** Детальний аналіз плинності кадрів (коефіцієнт утримання 96.15%), фінансові втрати від звільнень ($78.50K), аналіз причин (Voluntary vs Involuntary) та тривалість роботи перед звільненням.
*   **Employee Profile:** Інтерактивна картка працівника (на прикладі Joseph Powell) із деталізацією типу контракту, наявних сертифікацій (Cisco, CompTIA, Microsoft тощо) та прогресу онбордингу.
