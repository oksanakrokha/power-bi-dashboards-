# HR Analytics Dashboard

**Tool:** Power BI (Microsoft Fabric Warehouse + PostgreSQL)  
**Status:** Completed

## Pages
- Workforce Overview — headcount, turnover, probation
- Recruitment & Hiring — vacancies, time to fill, pipeline
- Retention & Tenure — retention rate, early attrition
- Termination Analysis — voluntary vs involuntary breakdown

## Dataset
- `employee_data.csv` — anonymized employee records
- `recruitment_data.csv` — vacancy and hiring data
